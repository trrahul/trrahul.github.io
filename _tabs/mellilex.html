Everything you need

Look up anything.
Understand everything.

MelliLex goes beyond a definition. Every lookup gives you meanings, pronunciation, formality, usage domains, memory tips, and example sentences — all from one keystroke.

Ctrl + Right-click
Global hotkey that works in any application — browser, PDF reader, ebook, email client. No copy-paste needed.
OCR capture
Automatically switches to OCR for non-selectable text — Kindle, Adobe Acrobat, Foxit, SumatraPDF.
Phrase support
Full idiom analysis with literal meaning, origin story, register, and usage context.
Explore mode
Dive deeper with formality analysis, domain examples, common mistakes, and practice exercises.
Spell check
SymSpell-powered corrections before every lookup, so typos never return wrong results.
Export
Save results to Markdown, plain text, or directly to Capacities as a structured word note.
Global lookup

Works in every app on your system

MelliLex registers a system-wide hook. Ctrl+right-click any word, in any window, and the result is on screen in seconds.

  • No need to switch to a browser or dictionary app
  • Automatic OCR fallback for PDFs and ebooks
  • Runs quietly in the system tray — zero friction
Explore mode

Go deeper than the definition

Explore mode unpacks a word across every dimension — where it's used, how to use it correctly, and how to make it stick.

  • Domain breakdown: academic, legal, creative, business
  • Common mistakes with correct alternatives explained
  • AI-generated practice exercises, regenerated on demand
  • Formality score from casual to highly formal
